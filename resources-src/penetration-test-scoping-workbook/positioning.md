# Positioning

## Title options

1. **Penetration Test Scoping Workbook** - direct, search-aligned, and suited to a working document rather than a narrative book.
2. **Scope the Test Before It Starts** - outcome-led, with a stronger editorial hook for a retail ebook listing.
3. **The SaaS Team's Penetration Test Scope Kit** - identity-led, aimed at the highest-fit Sthuthi buyer.

Chosen title: **Penetration Test Scoping Workbook** because the user specified it and the title states the product plainly.

## Back-cover blurb

A penetration test can only answer the questions its scope makes testable. This workbook helps SaaS, API, cloud, mobile, and AI product teams define the systems, roles, tenant boundaries, critical workflows, test rules, evidence, and retesting terms before an authorized assessment begins.

It includes twenty editable worksheets, a one-page scope brief, rules-of-engagement fields, a vendor scorecard, and a completed multi-tenant SaaS example. The method works backward from the decision the report must support, so the resulting scope is useful to engineers, security reviewers, customers, and auditors.

Complete it with your product, engineering, security, and legal owners, then issue a scope that a testing provider can price, authorize, execute, and report against.
