# Sthuthi Securities Resource Library Production Plan

Date: 4 November 2026

Each guide targets 9,000-12,000 words plus worksheets, diagrams, sources, and front/back matter. Every guide ships as Markdown, DOCX, PDF, and EPUB. All finished files are listed on `/resources` and downloaded through the server allowlist.

## Evidence rules

1. Prefer current primary sources: NIST, CISA, FTC, AICPA, OWASP, CIS, CSA, AWS, Microsoft, Google Cloud, and standards owners.
2. Record the publication/version date for requirements likely to change.
3. Separate an observed source statement from Sthuthi's recommendation.
4. Treat a missing artifact as unknown, not proof that a control does not exist.
5. Never claim that a questionnaire, certification, or test proves security beyond its stated scope and date.
6. Use complete visible URLs in every Sources section.
